# Brand mark variants (A/B)

**Naming (locked):** product = `agent-bom`; logo/mark = **BOM** (agent in the O).
Do not ship a product rename to bare “BOM”.

Canonical mark: `../mark-{light,dark}.svg` — **BOM with agent O**, antenna,
round eyes and a subtle smile. The mark has no decorative status bars.
Historical variants below do not define the current product mark.

Do not promote alternatives into the product UI without an explicit brand
decision. Optional historical sketches may remain under this folder for archive
only.

Accent: emerald → cyan. Edit `docs/images/brand/` first, then copy to
`ui/public/brand/` and regenerate favicon / site-docs marks.
